# Snapgrab — frontend

Next.js 16 (App Router) + TypeScript + Tailwind v4 + Framer Motion.

See the root-level `README.md` (one folder up) for the full architecture
explanation, local dev steps, and deployment guide — this app is one half of
a two-part project and doesn't do anything useful without the `backend/`
service running alongside it.

Quick start:

```bash
cp .env.local.example .env.local
npm install
npm run dev
```
